# Output styles

See ../../README.md for the directory overview.

## Where it lives

Project: .claude/output-styles/. Global: C:\Users\pmcro\.claude\output-styles\.

## How to author it

1. Create a markdown file with description frontmatter; set keep-coding-instructions: true to keep default task instructions.
2. Select it with /output-style, /config or the outputStyle setting (filename without .md, or the name field).
3. Styles are usually personal, so prefer the global directory; put one in the project only if the team shares it.
