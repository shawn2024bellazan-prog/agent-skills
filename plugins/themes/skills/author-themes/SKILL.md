# Themes

See ../../README.md for the directory overview.

## Where it lives

Global only: C:\Users\pmcro\.claude\themes\*.json.

## How to author it

1. Each file has name, a built-in base preset (for example dark) and an overrides map of color tokens.
2. Create interactively with /theme or write the JSON by hand; select it as custom:<slug>.
3. Files are hot-reloaded when they change.
