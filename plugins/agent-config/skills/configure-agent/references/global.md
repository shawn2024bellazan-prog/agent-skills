# .agents/ (global)

> Your personal configuration across all projects

**Scope:** global  (C:\Users\pmcro\.agents\)

The global counterpart to the project directory. Files here apply to every project you work in and are never committed to any repository. Contents: AGENTS.md (personal preferences), settings.json (default settings), keybindings.json (custom keyboard shortcuts), themes/, projects/ (auto memory), rules/, skills/, commands/, output-styles/, agents/, workflows/, agent-memory/ (persistent memory for subagents with memory: user).
